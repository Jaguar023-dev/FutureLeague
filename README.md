# ⚽ Future League - Realistic Football Game

A mobile-first, realistic 3D football game built with React Three Fiber and TypeScript.

## 🎮 Features

- **Realistic 3D Graphics** - Powered by Three.js
- **Mobile Touch Controls** - Virtual joystick & action buttons
- **Multiple Leagues** - Premier League, La Liga, World Cup, AFCON
- **Physics Engine** - Realistic ball physics with Cannon.js
- **Real Teams & Players** - Authentic teams with generated players
- **Tournament System** - Complete with trophies and awards

## 🚀 Quick Start

```bash
# Clone repository
git clone https://github.com/Jaguar023-dev/future-league.git

# Install dependencies
cd future-league
npm install

# Start development server
npm run dev
